# Dataset V2 — YOLOv8 Experiments

This folder contains the training, validation and improvement notebooks for Roboflow Dataset V2.

- `MMA3001_v2_training.ipynb`: Dataset preparation and baseline YOLOv8n training.
- `MMA3001_v2_validation.ipynb`: YOLOv8n test evaluation and performance analysis.
- `MMA3001_v2_improvement.ipynb`: YOLOv8s training experiment and validation results.

Dataset cleaning is handled by `src/dataset_preparation.py`.
